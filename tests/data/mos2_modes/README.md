# Mode-planning regression fixture

Generated by the local QE 7.4 / Phonopy MoS2 smoke test on October 28, 2026.
The coarse calculation is not a scientific benchmark. These files test
atom registration, irreducible partner bases and normal-coordinate units.
Pseudopotentials and electronic wavefunctions are not needed or included.
Synthetic exactly covariant complex dielectric derivatives are used in the
mode reconstruction tests, so finite-step DFT errors are not confused with
algebra or basis errors.
